# Socio-cognitive_AWE

This repository contains scripts and data for our AWE paper. Additional project details will be shared after the review process is complete.

Analysis_AES_Nov2025.r includes the statistical analysis code for Research Questions 2 and 3, with notes to help readers reuse or follow the workflow. WC1.csv is the dataset used for the statistical analysis.

Python scripts for the LLM-based essay rating are also included.

To use KeystrokeLoggingAnalysis.R, please first download the KLiCKe corpus from the following repository: https://github.com/terryyutian/KLiCKe-Corpus. This link also contains essential information about the corpus used in our analysis.
